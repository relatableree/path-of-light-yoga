# Path of Light Yoga Studio

A four-page website for a fictional yoga studio, built in 2022 as a college HTML & CSS exercise. The studio and its text come from a textbook case study; the code, layout and styling are my own, and I've since polished it to work well on phones.

- `index.html`: welcome, features and address
- `classes.html`: the three class types
- `schedule.html`: weekday and weekend timetables
- `contacts.html`: a contact form checked by JavaScript (`scripts/contact.js`); it doesn't send anything

All pages share `stylesheets/yoga.css`. Photo credits are listed at the top of that file.
